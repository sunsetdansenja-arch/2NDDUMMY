# SALT DEPARTMENT — Website Assets

Folder kerja untuk persiapan website **saltdepartment.asia**.

## Struktur
- `assets/brand/` — logo, wordmark, favicon, brand marks
- `assets/hero/` — hero banner dan campaign imagery
- `assets/products/` — foto produk boardshort dan surfwear
- `assets/editorial/` — lifestyle, surfing, beach, dan editorial photography
- `assets/lookbook/` — foto koleksi dan campaign lookbook

## Panduan upload
- Gunakan nama file lowercase dan pisahkan kata dengan tanda hubung.
- Contoh: `hero-surf-coast-01.webp`, `boardshort-quiksilver-front-01.jpg`.
- Pertahankan file asli; jangan overwrite aset sumber saat melakukan optimasi.
- Prioritaskan WebP untuk aset website, tetapi simpan master/original bila diperlukan.
- Untuk foto produk, gunakan ID/SKU konsisten agar mudah dihubungkan ke katalog.

Belum ada desain atau implementasi website yang dibuat di folder ini. Folder ini hanya menyiapkan tempat aset.
